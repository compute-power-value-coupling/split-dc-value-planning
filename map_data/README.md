# 底图数据(国家地图仿真图 M1–M4 使用)

## 投稿用：天地图标准地图数据(审图号 GS(2024)0650号) —— 未随代码包分发
本包不包含 `中国_省.geojson`。程序在该文件存在时优先使用它，否则自动退回下方随包提供的 ECharts 简化数据。正式底图按以下步骤另行获取：
1. 登录天地图 → 服务中心 → 数据资源 → 行政区划可视化(https://cloudcenter.tianditu.gov.cn/administrativeDivision)，
   下载省级 GeoJSON `中国_省.geojson`。记录下载日期并截图存档(页面注明数据“仅供地图可视化使用”)。
2. 放到本目录：`map_data/中国_省.geojson`(也可命名为 `tianditu_province.geojson`)，重新运行 `plot_paper_figures`，无需重跑仿真。
3. 程序检测到该文件后自动：
   - 使用原始边界坐标，不做任何简化或改动(只做 Albers 投影显示)；
   - 主图绘至海南岛最南端，南海诸岛与断续线按真实数据(同一投影)缩绘入“南海诸岛”附图，附图带 500 km 比例尺；
   - 附图放在台湾以东的空白海域，自动避开所有陆地与界线；二维图中最后绘制，不被流线、节点、标注压盖；
   - 国界/海岸线由省界中只属于一个省的边自动提取；图右下角标注“审图号: GS(2024)0650号”。

图注建议：
- 中文：注：该图基于天地图（国家地理信息公共服务平台）下载的审图号为GS(2024)0650号的标准地图制作，底图边界无修改。
- 英文：Base map: Tianditu (National Platform for Common GeoSpatial Information Services), approval No. GS(2024)0650; boundaries not modified.
